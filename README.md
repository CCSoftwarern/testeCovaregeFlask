# 🧪 Flask App com Testes e Cobertura

Este projeto é um exemplo simples de aplicação Flask com testes automatizados usando `pytest` e medição de cobertura com `coverage.py`.

---

## 🚀 Como executar

### ✅ 1. Criar ambiente virtual

```bash
py -3 -m venv .venv

.venv\Scripts\activate  # Windows

### ✅ 2. Ativar o ambiente virtual

.venv\Scripts\activate  # Windows
# ou
source .venv/bin/activate  # Linux/macOS


### ✅ 3. Instalar as dependências
pip install flask pytest coverage

🧪 Executar os testes com cobertura
1. Rodar os testes com cobertura

coverage run -m pytest


2. Ver relatório no terminal
coverage report
